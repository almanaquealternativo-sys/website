## Propósito

Este almanaque nasce como uma base editorial recorrente. A primeira etapa organiza as seções, cria uma identidade visual inicial e permite publicar novos conteúdos por arquivos Markdown.

## Próximas camadas

- Newsletter para capturar interesse e avisar novas publicações.
- Área de login para membros.
- Pagamento recorrente para conteúdos exclusivos.
- Taxonomia por temas, tags e trilhas de estudo.
